# Роли и Беседы - Руководство пользователя

## 🎭 Система ролей

### Предустановленные роли
- **Преподаватель** - структурирует объяснения, проверяет знания, даёт задания
- **IT‑инженер** - разбирает ошибки, даёт план фикса, пишет сниппеты
- **Доктор** - образовательная информация и маршрутизация (без диагноза)
- **Садовод** - рекомендации по уходу, сезонные чек‑листы
- **Юрист** - образовательная информация, общие правовые вопросы
- **Психолог** - поддержка, советы по саморазвитию
- **Переводчик** - переводы, объяснения языковых нюансов
- **Аналитик** - анализ данных, структурирование информации

### Команды ролей
- `/roles` - показать меню выбора ролей
- `/role_clear` - сбросить текущую роль (вернуться к базовому форматированию)

### Создание кастомных ролей
1. Используйте `/roles` и нажмите "➕ Создать свою роль"
2. Опишите желаемую роль в 1-2 предложениях
3. Бот сгенерирует структурированную роль с помощью prompt engineering
4. Выберите "Применить" для немедленного использования или "Сохранить" для будущего использования

## 💬 Система бесед

### Команды бесед
- `/save <название>` - сохранить текущую беседу
- `/conversations [страница]` - показать список сохранённых бесед
- `/switch <ID>` - переключиться на беседу
- `/rename <ID> <новое название>` - переименовать беседу
- `/delete <ID>` - удалить беседу (с подтверждением)

### Особенности
- Беседы сохраняют историю диалога и активную роль
- Поддерживается пагинация (5 бесед на страницу)
- Автоматическое управление контекстом с суммаризацией длинных диалогов

## 🧠 Управление контекстом

### Лимиты токенов
- **Мягкий лимит**: 300,000 токенов (начинается суммаризация)
- **Жёсткий лимит**: 800,000 токенов (принудительная суммаризация)
- **Максимум сообщений**: 50 (мягкий) / 100 (жёсткий)

### Суммаризация
- Автоматически срабатывает при превышении лимитов
- Сохраняет последние 15 сообщений + суммаризацию старых
- Суммаризация включается в контекст как отдельное сообщение

## 📊 Мониторинг (только для админов)

### Команды метрик
- `/rolemetrics` - показать метрики ролей и бесед
- `/metrics` - общие метрики системы

### Отслеживаемые метрики
- **Роли**: применения, создание кастомных, сбросы, сохранения
- **Беседы**: сохранения, переключения, переименования, удаления
- **Суммаризация**: срабатывания, сэкономленные токены, средняя длина

## 🔧 Технические детали

### Архитектура
- **Роли**: предустановленные + кастомные, композиция с базовым форматированием
- **Беседы**: отдельные таблицы в БД с RLS, сохранение роли и истории
- **Контекст**: умное управление с лимитами и суммаризацией
- **Метрики**: отдельный сборщик для ролей, бесед и суммаризации

### База данных
- `roles` - предустановленные роли
- `user_roles` - кастомные роли пользователей
- `conversations` - сохранённые беседы
- `conversation_messages` - сообщения бесед

### Безопасность
- RLS для всех таблиц
- Проверка принадлежности бесед пользователям
- Валидация входных данных
- Логирование всех операций

## 🚀 Развёртывание

1. Убедитесь, что все зависимости установлены
2. Запустите миграции БД (таблицы создаются автоматически)
3. Проверьте работу команд `/roles` и `/save`
4. Запустите тесты для проверки функциональности

## 📝 Логирование

Все операции с ролями и беседами логируются:
- Применение ролей
- Создание кастомных ролей
- Сохранение/переключение бесед
- Срабатывание суммаризации
- Ошибки и исключения

Логи доступны в стандартном выводе и файлах логов системы.
