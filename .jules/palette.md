## 2024-03-13 - Dashboard Tabs Missing ARIA\n**Learning:** The dashboard uses custom tabs without any WAI-ARIA roles, attributes, or keyboard support, which is completely inaccessible to screen reader users.\n**Action:** Always implement the full WAI-ARIA tab pattern: `role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`, and `role="tabpanel"` with `aria-labelledby` when creating custom tab interfaces.
