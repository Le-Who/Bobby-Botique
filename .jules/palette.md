## 2025-04-12 - Complete WAI-ARIA patterns on dynamic components
**Learning:** Dynamic components in this app (like custom tabs and dynamic error badges) often partially implement ARIA attributes. Tab patterns might have `role="tab"` and `aria-selected` toggling, but completely omit `id` references on the buttons and `aria-labelledby` on the content panels to physically associate them. Additionally, dynamically updating elements like error counters miss `aria-live` declarations to announce changes.
**Action:** When working on custom UI elements or dynamic widgets, always fully verify the complete ARIA pattern (e.g. `role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-controls`, `aria-labelledby`) and specifically check that any dynamic text replacements have an appropriate `aria-live` attribute.
