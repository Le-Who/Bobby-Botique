## 2025-02-14 - Fix Cross-Site Scripting (XSS) in Dashboard API injection
**Vulnerability:** The application fetches backend data via the `/api/` endpoints (such as `/api/keys`, `/api/errors`, etc.) and iterates over the JSON structure to construct dynamic DOM nodes. The data fields (`model_name`, error messages, and circuit breaker names) were interpolated directly into raw HTML string literals and inserted via `innerHTML`.
**Learning:** This injection creates a severe XSS vector where any compromised downstream system or log message payload containing raw `<script>` tags or inline DOM handlers (e.g. `<img onerror=...>`) could be executed under the context of the administrator viewing the dashboard. The framework doesn't natively sanitize strings injected inside template literals.
**Prevention:** To safely prevent XSS while maintaining dynamic template hydration, explicitly wrap dynamically inserted data using a DOM textNode-based escape helper (`function esc(s) { const d = document.createElement('div'); d.textContent = s ?? ''; return d.innerHTML; }`) instead of relying on direct string interpolation.
