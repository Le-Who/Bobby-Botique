## 2024-05-24 - Damerau-Levenshtein $O(n)$ space optimization

**Learning:** The previous implementation of the restricted Damerau-Levenshtein distance matrix allocated a full $O(m \cdot n)$ 2D matrix (`[[0] * (n + 1) for _ in range(m + 1)]`). Since strings being compared are short but similarity lookups happen very frequently (e.g., in judging games and facts where thousands of pairs might be evaluated), allocating the full matrix continuously adds meaningful garbage collection overhead. Since Damerau-Levenshtein calculation with adjacent transpositions only ever strictly accesses elements from the current row (`i`), the previous row (`i-1`), and two rows prior (`i-2`), retaining the entire matrix is unnecessary.

**Action:** Replace full $O(m \cdot n)$ 2D matrix allocation in Levenshtein variants with a rotating 3-row list reference trick (`d_prev2`, `d_prev1`, `d_curr = d_prev1, d_curr, d_prev2`), preserving string character access rules. This brings memory overhead per calculation to $O(n)$ and, since Python lists aren't recreated but re-assigned, it resulted in a ~20% execution speedup.
