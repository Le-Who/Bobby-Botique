# 🔧 Исправление проблемы с Tavily API

## 🚨 **Проблема**

Согласно логам, аккаунт Tavily был деактивирован:
```
"The account associated with this API key has been deactivated. If you wish to reactivate your subscription, please contact our team at support@tavily.com."
```

## 🔍 **Диагностика**

### **Шаг 1: Проверка текущего статуса**

Запустите диагностический скрипт:
```bash
python test_tavily_keys.py
```

Этот скрипт проверит:
- Ключи в переменных окружения
- Ключи в базе данных
- Работоспособность каждого ключа

### **Шаг 2: Проверка через Telegram бота**

Используйте команды администратора:
- `/checktavilykeys` - проверить статус ключей
- `/updatetavilykeys` - обновить ключи из переменных окружения

## ✅ **Решение**

### **Вариант 1: Реактивация аккаунта (Рекомендуется)**

1. **Обратитесь в поддержку Tavily:**
   - Email: support@tavily.com
   - Укажите ваш API ключ и опишите проблему
   - Попросите реактивировать аккаунт

2. **Проверьте статус подписки:**
   - Зайдите на [dashboard.tavily.com](https://dashboard.tavily.com)
   - Убедитесь, что подписка активна
   - Проверьте лимиты и использование

3. **Обновите ключи в боте:**
   ```bash
   python update_tavily_keys.py
   ```

### **Вариант 2: Создание нового аккаунта**

1. **Зарегистрируйтесь на [tavily.com](https://tavily.com)**
2. **Получите новый API ключ**
3. **Обновите переменную окружения:**
   ```bash
   TAVILY_API_KEYS=your_new_api_key
   ```
4. **Обновите ключи в боте:**
   ```bash
   python update_tavily_keys.py
   ```

### **Вариант 3: Временное отключение поиска**

Если нужно быстро восстановить работу бота без поиска:

1. **Отключите deepdive функциональность:**
   - Установите `TAVILY_API_KEYS=` (пустое значение)
   - Перезапустите бота

2. **Или используйте fallback поиск:**
   - Настройте альтернативный поисковый сервис
   - Обновите код для использования fallback

## 🔧 **Технические детали**

### **Структура базы данных**

Ключи Tavily хранятся в таблицах:
- `tavily_api_keys` - API ключи
- `tavily_key_usage` - статистика использования

### **Обновление ключей**

Функция `force_update_tavily_keys()` в `app/database.py`:
- Очищает старые ключи
- Добавляет новые из переменных окружения
- Сбрасывает кэш активных ключей

### **Логирование**

Все запросы к Tavily API логируются через `api_logger`:
- Время запроса
- Статус ответа
- Детали ошибок
- Использование кредитов
