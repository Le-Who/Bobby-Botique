# Разбор предложенных revisions и перенос в бот

Дата: 2026-09-29. База: `25e54f8a`. Материалы: локальные каталоги
`revisions/fable-5-1-max` и `revisions/mimo`; их оригиналы не изменялись.
Результат относится к рабочему дереву и локальным проверкам, не к VPS.

## Что фактически содержат выпуски

**fable-5-1-max** — отдельная Next.js/PostgreSQL операторская консоль:
конфигурация, отказы, restore, research budget, evals, SLO, access matrix,
daily readiness, evidence ledger и roadmap. В `bot-patches/` лежат отдельный
Python-бюджет, два offline-скрипта, статический реестр и документация. Сам бюджет
не подключён к research; notes предлагают будущую интеграцию.

**mimo** — отдельная консоль предложений, конфигурации, evals, сигналов и roadmap
со статическими начальными данными. После нормализации LF/CRLF reference-копия
бота совпала с нашей базой во всех сравниваемых файлах, кроме одного: её
`cmd_admin.py` содержит повреждённый символ перед статистикой документов, уже
исправленный в текущем проекте. Это не новая реализация функций бота.
В `console-data.ts` список `docLinks` и состояние намеренно сломанного примера
заданы литералами: это не исполняемый гейт ссылок репозитория.

Обе консоли полезны как материал для ревью. Их `shipped`, проценты, ручные
evidence-записи и synthetic metrics не являются доказательством изменения бота,
прохождения его тестов или работы deployment. Консоли не запускались с реальной
БД и не подключались к боту.

| Неизвестный usage (T-04/T-11) | Реализован для изменённого research-пути: known и reserved раздельно, terminal event. Универсальный usage-ledger и биллинг не заявляются. |

| Консоль памяти (T-07) | Адаптирована в существующий `/memory`: полный факт, страницы, возврат, удаление. Атомарная правка с provenance — отдельный MEM-3; одной правки UI недостаточно. |
| Новый универсальный provider (T-09) | Отложен до конкретной capability/пользы. Ещё один адаптер не гарантирует качество и добавляет поддержку. |

## Реализованные изменения и границы

### Документы и память

`msg_document.handle_document_question` передаёт выбранный `document_id` в
`ai_document`. Внутри существующего privacy lease повторно проверяются metadata
и content для того же владельца. Недоступный выбранный файл не заменяется
последним загруженным. Вызовы без явного ID пока сохраняют прежний выбор последнего
файла; полное согласование загрузки/active state — следующий DOC-2.

В `/memory` кнопка чтения открывает факт по owner + ID и отсекает expired rows.
Текст разбивается по 1 400 Unicode codepoints, показывается буквально без parse
mode и web preview; для него не создаётся Reader/Telegraph-копия. На каждой
странице доступны удаление и возврат к исходному списку. Редактирование фактов
и новый интерфейс графа не реализованы.

### Research

`ResearchBudget` отвечает за admission, а не за outcome генерации/Telegram.
Один handler-owned бюджет покрывает fallback-chain, включая ожидание fallback
ключей/статусов. Начальная проверка ключа, финальная доставка и persistence не
входят в этот интервал. Самостоятельный `AgenticSearch.run()` получает свой бюджет.

Резерв синтеза — `min(15 секунд, timeout / 6)`, максимум три попытки; прежние
`AGENTIC_TIMEOUT_SECONDS`, `AGENTIC_MAX_PAGES`, `AGENTIC_MAX_TOKENS` используются
без новых env. Токены — мягкий допуск следующего вызова, не жёсткий provider cap:
уже начатый вызов может превысить лимит, один финальный синтез допускается после
его исчерпания. Отсутствующий usage/ошибка/отмена резервирует 4 000 токенов;
нулевой подтверждённый usage остаётся нулём. Резерв не является ценой.

Async timeout отменяет cooperative provider/tool work. Cleanup ожидает задачи;
это не hard realtime guarantee и не обещание отмены расходов на сервере provider.
Завершённые результаты смешанной tool-batch сохраняются, отменяются только
неоконченные. Внешняя отмена распространяется вызывающему коду.

### Статические проверки

`scripts/check_env_registry.py` читает Python AST в `app/` и `bot.py`, известные
env helpers и LoggingSettings mapping; сравнивает с `docs/config-registry.json`.
Deployment означает явные `docker -e/--env NAME=`, compose — текущий list-синтаксис.
Динамические имена, произвольные alias/wrappers, scripts-only окружение, shell
indirection, requiredness, hot reload и успешность деплоя не выводятся автоматически.
Реестр не содержит live values и не заменяет фактические readers. Обновление:
`python scripts/check_env_registry.py --write`, затем review изменения источника.

`scripts/check_docs_links.py` проверяет текущие Markdown guides offline, включая
relative/image/reference definitions, inline-code headings, повторные headings,
encoded paths и HTML anchors. Это ограниченный parser, не весь CommonMark.
Датированные отчёты, `superpowers/`, `.jules/`, CHANGELOG и maintainer queue
проверяются отдельно с `--include-historical`; `revisions/` исключён как внешний
материал. Broken historical links не скрывают ошибки текущих guides.

Ruff также исключает исходные `revisions/`; перенесённый код проверяется обычными
проектными командами. Runtime зависимости и lockfile не менялись.
