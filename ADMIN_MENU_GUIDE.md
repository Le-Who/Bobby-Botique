# 🔧 РУКОВОДСТВО ПО АДМИН-МЕНЮ GEMAI BOT

## 🚀 **БЫСТРЫЙ СТАРТ**

### 1. **Откройте чат с ботом**
### 2. **Отправьте команду**: `/admin`
### 3. **Выберите нужный раздел** из меню

---

## 🛡️ **РАЗДЕЛ БЕЗОПАСНОСТИ**

### **Доступные режимы:**
- 🔒 **Standard** - Стандартные настройки (рекомендуется)
- 🟡 **Relaxed** - Расслабленные настройки (меньше блокировок)
- 🟢 **Disabled** - Отключенные (только для отладки!)
- 🔴 **Aggressive** - Агрессивные (максимальная защита)
- 🔄 **Auto** - Автоматическое переключение

### **Дополнительные настройки:**
- **Fallback** - Автоматическое переключение настроек при проблемах
- **Описание режимов** - Подробная справка по каждому режиму

---

## 🐛 **РАЗДЕЛ ОТЛАДКИ**

### **Debug режим:**
- **Включен** - Подробная информация о работе бота
- **Отключен** - Только основные сообщения

### **Уровень логов:**
- **DEBUG** - Максимальная детализация
- **INFO** - Основная информация
- **WARNING** - Только предупреждения и ошибки
- **ERROR** - Только ошибки

### **Логи безопасности:**
- **Включены** - Отслеживание всех решений по безопасности
- **Отключены** - Базовое логирование

---

## ⚡ **РАЗДЕЛ ПРОИЗВОДИТЕЛЬНОСТИ**

### **Кэширование:**
- **Включено** - Ускорение повторных запросов
- **Отключено** - Каждый запрос обрабатывается заново

### **TTL кэша:**
- **24 часа** - Для активного использования
- **48 часов** - Для умеренного использования
- **72 часа** - Для редкого использования (рекомендуется)
- **168 часов** - Для очень редкого использования

### **Максимальное количество попыток:**
- **1 попытка** - Быстро, но может не сработать
- **2 попытки** - Баланс скорости и надежности
- **3 попытки** - Рекомендуемое значение
- **5 попыток** - Максимальная надежность

### **Таймаут запросов:**
- **30 секунд** - Быстро, но может не успеть
- **60 секунд** - Рекомендуемое значение
- **120 секунд** - Для медленных соединений
- **300 секунд** - Для очень медленных соединений

---

## 🔧 **РАЗДЕЛ ФУНКЦИЙ**

### **Safety Fallback:**
- **Включен** - Автоматическое переключение настроек безопасности
- **Отключен** - Использование только указанных настроек

### **Упрощение промптов:**
- **Включено** - Удаление проблемных символов при ошибках
- **Отключено** - Промпты не изменяются

### **System Instruction Fallback:**
- **Включен** - Отключение system_instruction при проблемах
- **Отключен** - System instruction всегда используется

---

## 👁️ **ПРОСМОТР НАСТРОЕК**

### **Что показывает:**
- Все текущие настройки, сгруппированные по категориям
- Значения из базы данных (если изменены)
- Значения по умолчанию (если не изменены)

## ⚠️ **ВАЖНЫЕ ЗАМЕЧАНИЯ**

### **Безопасность:**
1. **Режим `disabled`** используйте только для отладки
2. **Не отключайте** safety fallback без необходимости
3. **Логируйте** важные изменения

### **Производительность:**
1. **TTL кэша** не должен превышать 168 часов (7 дней)
2. **Количество попыток** не должно быть больше 5
3. **Таймауты** не должны быть меньше 30 секунд

### **Применение изменений:**
1. **Большинство настроек** применяются немедленно
2. **Некоторые настройки** требуют перезапуска бота
3. **Проверяйте логи** после изменений

---

## 🆘 **РЕШЕНИЕ ПРОБЛЕМ**

### **Проблема: Настройки не применяются**
**Решение:** Перезапустите бота

### **Проблема: Ошибка доступа к админ-панели**
**Решение:** Проверьте, что ваш ID указан в `ADMIN_ID`

### **Проблема: Настройки сбрасываются**
**Решение:** Проверьте права доступа к базе данных

### **Проблема: Бот не отвечает**
**Решение:** Проверьте логи и перезапустите бота

## 🎯 **РЕКОМЕНДАЦИИ**

### **Начните с:**
1. **SAFETY_MODE = relaxed** - для тестирования
2. **DEBUG_MODE = true** - для отладки
3. **LOG_LEVEL = DEBUG** - для детального логирования

### **Постепенно настройте:**
1. **TTL кэша** под ваше использование
2. **Количество попыток** под стабильность API
3. **Таймауты** под скорость соединения

### **Мониторьте:**
1. **Логи** после изменений
2. **Производительность** бота
3. **Количество ошибок** API
