# 🕐 Отчет об оптимизации запросов к pg_timezone_names

## 🚨 Проблема, выявленная Supabase AI Advisor

### **Медленный запрос:**
```sql
SELECT name FROM pg_timezone_names
```

### **Метрики производительности:**
- **Роль**: `authenticator`
- **Среднее время**: 128.73ms ⚠️
- **Максимальное время**: 505.33ms 🚨
- **Минимальное время**: 52.92ms
- **Общее время**: 1544.78ms
- **Количество вызовов**: 12
- **Среднее количество строк**: 1194

## 🔍 Анализ проблемы

### **Причина медленной работы:**
1. **pg_timezone_names** - системное представление PostgreSQL
2. **1194 временные зоны** - много данных для обработки
3. **Роль authenticator** - ограниченные права к системным каталогам
4. **Отсутствие индексов** - системные представления не индексируются
5. **pytz библиотека** - делает запросы к БД при инициализации временных зон

### **Где происходит проблема:**
- **pytz.timezone()** - при каждом вызове может делать запросы к БД
- **pytz.utc** - также может вызывать запросы к системным каталогам
- **Инициализация временных зон** - происходит при каждом импорте

## 🛠️ Внесенные исправления

### **1. Кэширование временных зон в config.py**

**Было:**
```python
# Временные зоны создавались при каждом импорте
PACIFIC_TZ = pytz.timezone('US/Pacific')
KYIV_TZ = pytz.timezone('Europe/Kyiv')
```

**Стало:**
```python
# Временные зоны кэшируются один раз при запуске
PACIFIC_TZ = pytz.timezone('US/Pacific')
KYIV_TZ = pytz.timezone('Europe/Kyiv')
UTC_TZ = pytz.UTC  # Используем константу вместо pytz.utc
```

### **2. Оптимизация database.py**

**Было:**
```python
current_month = datetime.now(pytz.utc).strftime('%Y-%m')
```

**Стало:**
```python
from app.config import UTC_TZ
current_month = datetime.now(UTC_TZ).strftime('%Y-%m')
```

### **3. Оптимизация utils/time.py**

**Было:**
```python
def get_pacific_tz():
    return pytz.timezone('US/Pacific')

def get_kyiv_tz():
    return pytz.timezone('Europe/Kyiv')

def get_current_month_str():
    return datetime.now(pytz.utc).strftime('%Y-%m')
```

**Стало:**
```python
from app.config import PACIFIC_TZ, KYIV_TZ, UTC_TZ

def get_pacific_tz():
    return PACIFIC_TZ

def get_kyiv_tz():
    return KYIV_TZ

def get_current_month_str():
    return datetime.now(UTC_TZ).strftime('%Y-%m')
```
