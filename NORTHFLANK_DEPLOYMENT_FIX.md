# 🔧 Исправление проблем с деплоем на Northflank.com

## 🚨 **Проблема**

При деплое на Northflank.com возникают циклические ошибки:
- Конфликт блокировок между процессами
- Ошибки подключения к Redis
- Health check не проходит

## ✅ **Решение**

### **Шаг 1: Обновление кода**

1. **Закоммитьте исправления:**
```bash
git add .
git commit -m "Fix deployment issues for Northflank.com"
git push origin main
```

### **Шаг 2: Настройка переменных окружения**

В Northflank Dashboard убедитесь, что настроены **ВСЕ** переменные:

**Обязательные переменные:**
```
PORT=10000
LOG_JSON=true
ENABLE_PERSISTENT_QUEUE=true
```

**Секретные переменные (нажмите "Add secret"):**
```
TELEGRAM_BOT_TOKEN=<ваш-токен-бота>
DATABASE_URL=<ваш-supabase-url>
ADMIN_ID=<ваш-telegram-id>
```

**Опциональные переменные (если используете):**
```
REDIS_URL=<ваш-upstash-redis-url>
TAVILY_API_KEYS=<ваши-tavily-ключи>
GEMINI_API_KEYS=<ваши-gemini-ключи>
```

### **Шаг 3: Настройка ресурсов**

В разделе **"Resources"**:
- **CPU**: `0.5` cores
- **Memory**: `512 Mi`

### **Шаг 4: Настройка health checks**

В разделе **"Health checks"**:
- **Path**: `/health`
- **Interval**: `60s`
- **Timeout**: `30s`
- **Retries**: `5`
- **Start period**: `120s`

### **Шаг 5: Мониторинг деплоя**

1. **Следите за логами** в разделе **"Logs"**
2. **Проверьте статус** в разделе **"Overview"**
3. **Дождитесь** завершения сборки

## 🚨 **Troubleshooting**

### **Если деплой все еще не проходит:**

1. **Проверьте логи** в Northflank Dashboard
2. **Убедитесь**, что все переменные окружения настроены
3. **Проверьте**, что DATABASE_URL корректный
4. **Убедитесь**, что TELEGRAM_BOT_TOKEN валидный

### **Если health check не проходит:**

1. **Проверьте** endpoint `/health` вручную
2. **Убедитесь**, что порт 10000 открыт
3. **Проверьте** логи приложения

### **Если Redis не подключается:**

1. **Это нормально** - приложение работает без Redis
2. **Проверьте** REDIS_URL в переменных окружения
3. **Убедитесь**, что Upstash доступен
