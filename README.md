# 🤖 Gemini Bot - Telegram AI-Агент

Мощный Telegram-бот с интеграцией Google Gemini AI, веб-поиском, обработкой документов и расширенной аналитикой.

## 🌟 Основные возможности

### 💬 AI-Чат
- **Мультимодельная поддержка**: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.5-flash-lite`
- **Контекстные беседы**: Сохранение истории диалогов
- **Системные инструкции**: Настройка поведения бота
- **Умное управление токенами**: Автоматическое ограничение контекста

### 🔍 Веб-поиск и анализ
- **Быстрый поиск**: `? вопрос` - получение фактических ответов
- **Глубокий анализ**: `?? вопрос` - детальное исследование с источниками
- **Поиск по изображениям**: `??` + фото - анализ и поиск по картинкам
- **Интеграция с Tavily**: Продвинутый веб-поиск с источниками

### 📄 Обработка документов
- **Поддержка форматов**: PDF, DOCX
- **Извлечение текста**: Автоматическая обработка загруженных файлов
- **Контекстные вопросы**: Задавайте вопросы по содержимому документов
- **Сохранение в БД**: Документы сохраняются для последующего использования

### 🖼️ Анализ изображений
- **Визуальный анализ**: Описание и анализ загруженных изображений
- **Поиск по картинкам**: Генерация поисковых запросов на основе изображений
- **Мультимодальные ответы**: Комбинирование текста и изображений

### 👥 Групповые чаты
- **Регистрация групп**: Автоматическое управление групповыми чатами
- **Статистика активности**: Отслеживание сообщений и пользователей
- **Модерация**: Контроль доступа и активности

## 🚀 Быстрый старт

### Для пользователей

1. **Начните чат**: Просто напишите сообщение боту
2. **Быстрый поиск**: `? Как работает квантовая физика?`

## 🏗️ Архитектура

### Технологический стек

- **Python 3.11+**: Основной язык разработки
- **python-telegram-bot**: Telegram Bot API
- **Google Gemini API**: AI модели
- **Tavily API**: Веб-поиск
- **PostgreSQL (Neon)**: База данных
- **asyncpg**: Асинхронная работа с БД
- **Flask + Hypercorn**: Веб-сервер для health checks

### Модульная структура

```
gemaibotv2/
├── app/
│   ├── config.py          # Конфигурация приложения
│   ├── database.py        # Работа с базой данных
│   ├── services.py        # Внешние API (Gemini, Tavily)
│   ├── prompts.py         # Промпты для AI моделей
│   ├── metrics.py         # Система метрик
│   ├── alerts.py          # Система уведомлений
│   ├── cache.py           # Кэширование результатов
│   ├── queue.py           # Очередь задач
│   ├── document_processor.py # Обработка документов
│   ├── group_chat.py      # Управление групповыми чатами
│   ├── state.py           # Управление состоянием
│   ├── handlers/          # Обработчики команд и сообщений
│   └── utils/             # Утилиты (форматирование, время)
├── bot.py                 # Точка входа
├── requirements.txt       # Зависимости
├── Dockerfile            # Docker контейнер
└── docker-compose.yml    # Docker Compose
```

## 🔧 Установка и развертывание

### Локальная установка

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd gemaibotv2
```

2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

3. **Настройка переменных окружения**
```bash
# Создайте .env файл
TELEGRAM_BOT_TOKEN=your_bot_token
DATABASE_URL=your_neon_database_url
GEMINI_API_KEYS=key1,key2,key3
TAVILY_API_KEYS=key1,key2
ADMIN_ID=your_telegram_id
```

4. **Запуск**
```bash
python bot.py
```

### Docker развертывание

1. **Сборка образа**
```bash
docker build -t gemini-bot .
```

2. **Запуск с Docker Compose**
```bash
docker-compose up -d
```

### Развертывание на Render

1. **Подключение репозитория** к Render
2. **Настройка переменных окружения** в панели Render
3. **Автоматическое развертывание** при push в main
