# Gemini Bot v2 - Расширенная версия

Многофункциональный Telegram AI-агент с интеграцией Google Gemini и Tavily для поиска. Теперь с поддержкой метрик, кэширования, групповых чатов и обработки документов.

## 🚀 Новые возможности

### 📊 Система метрик и мониторинга
- **Автоматический сбор метрик**: время ответа, количество запросов, ошибки
- **Мониторинг API**: использование Gemini и Tavily API
- **Статистика кэша**: эффективность кэширования результатов
- **Команды для админов**: `/metrics`, `/cachestats`, `/queuestats`

### 🚨 Система алертов
- **Автоматические уведомления** при исчерпании API лимитов
- **Мониторинг ключей**: Gemini и Tavily
- **Умные алерты** с защитой от спама (cooldown)

### 🗄️ Кэширование результатов поиска
- **Умное кэширование** поисковых запросов
- **Автоматическая очистка** устаревших записей
- **Экономия API вызовов** и улучшение скорости ответов
- **Команда очистки**: `/clearcache`

### 📄 Поддержка документов
- **PDF документы**: извлечение текста и изображений
- **Word документы** (.docx, .doc): текст и таблицы
- **Автоматическое сохранение** в базу данных
- **Максимальный размер**: 50MB, до 100 страниц

### 👥 Групповые чаты
- **Регистрация групп**: `/registergroup`
- **Управление участниками**: автоматическое добавление/удаление
- **Статистика групп**: `/groupstats`
- **Логирование сообщений** для аналитики

### ⚡ Очередь задач
- **Фоновая обработка** длительных операций
- **Приоритеты задач**: низкий, обычный, высокий, срочный
- **Автоматические повторы** при ошибках
- **Мониторинг очереди**: `/queuestats`

## 🛠️ Установка и настройка

### Зависимости
```bash
pip install -r requirements.txt
```

### Переменные окружения
```env
TELEGRAM_BOT_TOKEN=your_bot_token
GEMINI_API_KEYS=key1,key2,key3
TAVILY_API_KEYS=key1,key2,key3
DATABASE_URL=postgresql://user:pass@host:port/db
ADMIN_ID=your_telegram_id
PORT=10000
```

### Дополнительные библиотеки для документов
```bash
pip install PyPDF2 python-docx PyMuPDF
```

## 📋 Команды

### Основные команды
- `/start` - Информация о боте
- `/newchat` - Новый чат
- `/model` - Выбор модели
- `/setprompt [текст]` - Системная инструкция
- `/res` - Вкл/выкл режим исследования

### Поиск
- `? вопрос` - Быстрый поиск
- `?? вопрос` - Глубокое исследование
- `?? + фото` - Поиск по изображению

### Админ-команды
- `/adduser <id>` - Добавить пользователя
- `/deluser <id>` - Удалить пользователя
- `/listusers` - Список пользователей
- `/keystatus` - Статус ключей Gemini
- `/credits` - Кредиты Tavily
- `/listmodels` - Доступные модели

### Новые админ-команды
- `/metrics` - Метрики производительности
- `/cachestats` - Статистика кэша
- `/queuestats` - Статистика очереди
- `/clearcache` - Очистить кэш

### Групповые чаты
- `/registergroup` - Зарегистрировать группу
- `/groupstats` - Статистика группы

## 🏗️ Архитектура

### Новые модули
- `app/metrics.py` - Система метрик
- `app/alerts.py` - Система алертов
- `app/cache.py` - Кэширование
- `app/queue.py` - Очередь задач
- `app/document_processor.py` - Обработка документов
- `app/group_chat.py` - Групповые чаты

### База данных
Новые таблицы:
- `user_documents` - Документы пользователей
- `group_chats` - Групповые чаты
- `group_members` - Участники групп
- `group_messages` - Сообщения в группах
