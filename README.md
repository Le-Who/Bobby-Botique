# 🤖 Gemini Bot - Telegram AI-Агент

Мощный Telegram-бот с интеграцией Google Gemini AI, веб-поиском, обработкой документов и расширенной аналитикой.

## 🌟 Основные возможности

### 💬 AI-Чат
- **Мультимодельная поддержка**: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.5-flash-lite`
- **Контекстные беседы**: Сохранение истории диалогов
- **Системные инструкции**: Настройка поведения бота
- **Умное управление токенами**: Автоматическое ограничение контекста

### 🔍 Веб-поиск и анализ
- **Быстрый поиск**: `? вопрос` - получение фактических ответов
- **Глубокий анализ**: `?? вопрос` - детальное исследование с источниками
- **Поиск по изображениям**: `??` + фото - анализ и поиск по картинкам
- **Интеграция с Tavily**: Продвинутый веб-поиск с источниками

### 📄 Обработка документов
- **Поддержка форматов**: PDF, DOCX
- **Извлечение текста**: Автоматическая обработка загруженных файлов
- **Контекстные вопросы**: Задавайте вопросы по содержимому документов
- **Сохранение в БД**: Документы сохраняются для последующего использования

### 🖼️ Анализ изображений
- **Визуальный анализ**: Описание и анализ загруженных изображений
- **Поиск по картинкам**: Генерация поисковых запросов на основе изображений
- **Мультимодальные ответы**: Комбинирование текста и изображений

### 👥 Групповые чаты
- **Регистрация групп**: Автоматическое управление групповыми чатами
- **Статистика активности**: Отслеживание сообщений и пользователей
- **Модерация**: Контроль доступа и активности

## 🚀 Миграция на Supabase

### Обновления для Supabase.com
Проект был успешно мигрирован с Neon.tech на Supabase.com с оптимизациями для бесплатного тарифа:

#### **Оптимизации соединений:**
- **Pool Size**: Оптимизирован до 10 соединений (лимит Supabase free tier: 200 concurrent connections)
- **Keepalive**: TCP keepalive для стабильности соединений
- **Timeouts**: Увеличены до 60 секунд для Supabase
- **Session Settings**: Автоматическая оптимизация сессий
- **Connection Mode**: Рекомендуется Transaction pooler для лучшей производительности

#### **Улучшения производительности:**
- **Statement Timeout**: 60 секунд для длительных запросов
- **Idle Timeout**: 30 секунд для неактивных транзакций
- **Lock Timeout**: 30 секунд для блокировок
- **Connection Retry**: Улучшенная логика переподключения

#### **Обработка ошибок:**
- **Rate Limiting**: Специфичная для Supabase
- **Query Timeouts**: Детальная диагностика
- **Connection Issues**: Автоматическое восстановление

### Конфигурация для Supabase
```bash
# Обновите DATABASE_URL в переменных окружения
DATABASE_URL=postgresql://[user]:[password]@[host]:[port]/[database]

# Supabase автоматически применяет оптимизации при подключении
```

### Переменные окружения для Supabase
```bash
# Основные настройки
TELEGRAM_BOT_TOKEN=your_bot_token
DATABASE_URL=postgresql://postgres:[password]@[project].supabase.co:6543/postgres?pgbouncer=true&pool_mode=transaction
GEMINI_API_KEYS=key1,key2,key3
TAVILY_API_KEYS=key1,key2
ADMIN_ID=your_telegram_id
PORT=10000

# Дополнительные настройки (опционально)
LOG_JSON=true
REDIS_URL=your_redis_url
ENABLE_PERSISTENT_QUEUE=false
```

### Получение DATABASE_URL из Supabase
1. Войдите в [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в Settings → Database
4. Скопируйте Connection string (URI)
5. Замените `[YOUR-PASSWORD]` на ваш пароль базы данных

### Типы подключения к Supabase

#### **Transaction Pooler (Рекомендуется для нашего проекта)**
```bash
# Используйте этот формат для лучшей производительности
DATABASE_URL=postgresql://postgres:[password]@[project].supabase.co:6543/postgres?pgbouncer=true&pool_mode=transaction
```

**Преимущества:**
- ✅ **Оптимально для stateless приложений** (как наш Telegram бот)
- ✅ **Краткие транзакции** - каждый запрос независим
- ✅ **Лучшая производительность** с asyncpg
- ✅ **Меньше накладных расходов** на управление сессиями

#### **Session Pooler (Альтернатива)**
```bash
# Используйте только при необходимости IPv4 подключения
DATABASE_URL=postgresql://postgres:[password]@[project].supabase.co:5432/postgres?pgbouncer=true&pool_mode=session
```

**Когда использовать:**
- ⚠️ Только при подключении через IPv4 сеть
- ⚠️ Менее эффективно для кратких транзакций

### Troubleshooting Supabase Issues

#### **Common Connection Problems:**
- **Connection Limit Exceeded**: Убедитесь, что max_size=10 в настройках пула (лимит 200 concurrent connections)
- **Query Timeout**: Проверьте statement_timeout (60s) и idle_timeout (30s)
- **Rate Limiting**: Мониторьте использование API через /metrics
- **Message Size Limit**: Максимальный размер сообщения 250 KB

#### **Performance Optimization:**
- **Connection Pooling**: Автоматически оптимизировано для 10 соединений (лимит 200 concurrent)
- **Query Optimization**: Используйте индексы для часто выполняемых запросов
- **Session Management**: Автоматическая очистка неактивных сессий
- **Transaction Mode**: Используйте Transaction pooler для лучшей производительности

## 🔧 Установка и развертывание

### Локальная установка

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd gemaibotv2
```

2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

3. **Настройка переменных окружения**
```bash
# Создайте .env файл
TELEGRAM_BOT_TOKEN=your_bot_token
DATABASE_URL=your_supabase_database_url
GEMINI_API_KEYS=key1,key2,key3
TAVILY_API_KEYS=key1,key2
ADMIN_ID=your_telegram_id
```

4. **Запуск**
```bash
python bot.py
```

### Docker развертывание

1. **Сборка образа**
```bash
docker build -t gemini-bot .
```

2. **Запуск с Docker Compose**
```bash
docker-compose up -d
```

### Развертывание на Render

1. **Подключение репозитория** к Render
2. **Настройка переменных окружения** в панели Render
3. **Автоматическое развертывание** при push в main
